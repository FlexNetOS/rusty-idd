# integrate-idd-spec-engine - Design

## Context

Integration work item `work:integrate-idd-spec-engine` maps capability `capability:idd-spec-engine` in layer `layer:executive-control-plane` to owner repos and validation gates generated by Rusty IDD.

## Goals / Non-Goals

**Goals:**

- Adopt the current owner/upstream surfaces before cutting local behavior.
- Keep Rusty IDD glue thin: DTO mapping, deterministic output, feature flags, validation, and CLI/API calls.
- Preserve `crates/core` as std-only.

**Non-Goals:**

- Starting host services, daemons, MCP servers, or vault relays from default Rusty IDD workflows.
- Downgrading a working upstream or owner-repo capability to simplify implementation.

## Decisions

- Implementation boundary: Use OpenSpec change in owning repos with Rusty IDD graph artifacts as planning input.
- Every consolidation cut must cite failing build, audit, platform, or scope evidence and include rollback.
- The first local Rusty IDD boundary is `rusty-idd spec status --json`, because
  status is already proven by the spec schema and filesystem artifact detector,
  and handoff/fleet automation needs deterministic lifecycle state before
  invoking runners.
- The JSON mode reuses the same status snapshot as human output to prevent
  divergent behavior.
- Handoff diagnostics are recorded as owner evidence, but this change does not
  mutate handoff or pull its runtime into default Rusty IDD workflows.

## Risks / Trade-offs

- Cross-repo ownership may require separate PRs in owner repos; this Rusty IDD change records the execution contract first.
- Native diagnostics may fail for upstream reasons; failures are evidence, not permission to pre-filter.

## Migration Plan

1. Re-read current owner repo docs, scripts, CI, and generated architecture artifacts.
2. Adopt the relevant current surfaces as-is or reference pinned upstream mirrors.
3. Run native diagnostics before cuts.
4. Add deterministic `spec status --json` and focused CLI tests.
5. Refresh `.idd/knowledge/*` and `.idd/MANIFEST.tsv`.
6. Run full Rusty IDD gates and owner-repo smoke tests.
