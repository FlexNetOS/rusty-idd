# integrate-agent-communication - Design

## Context

Integration work item `work:integrate-agent-communication` maps capability `capability:agent-communication` in layer `layer:coordination-communication` to owner repos and validation gates generated by Rusty IDD.

## Goals / Non-Goals

**Goals:**

- Adopt the current owner/upstream surfaces before cutting local behavior.
- Keep Rusty IDD glue thin: DTO mapping, deterministic output, feature flags, validation, and CLI/API calls.
- Preserve `crates/core` as std-only.

**Non-Goals:**

- Starting host services, daemons, MCP servers, or vault relays from default Rusty IDD workflows.
- Downgrading a working upstream or owner-repo capability to simplify implementation.

## Decisions

- Implementation boundary: add queue-aware owner-surface selection with
  `rusty-idd knowledge integration-owners --next`.
- The durable `.idd/knowledge/integration-owners.*` artifacts SHALL follow the
- highest-priority non-archived integration item by the same OpenSpec status
  logic used by `integration-status`.
- `--next-planned` remains available for automation that must skip active or
  scaffolded changes and select only still-planned work.
- Explicit selectors (`--change`, `--capability`, and `--work-item`) remain
  available for focused investigation.
- Every consolidation cut after this report must cite failing build, audit,
  platform, or scope evidence and include rollback.

## Risks / Trade-offs

- Cross-repo ownership may require separate PRs in owner repos; this Rusty IDD change records the execution contract first.
- Native diagnostics may fail for upstream reasons; failures are evidence, not permission to pre-filter.

## Migration Plan

1. Add `--next` and `--next-planned` to `knowledge integration-owners`.
2. Update Make/Just durable owner-surface generation to use `--next`.
3. Regenerate `.idd/knowledge/integration-owners.*`; it should select
   `integrate-agent-communication`.
4. Apply the thinnest Rusty IDD boundary and focused tests.
5. Refresh `.idd/knowledge/*` and `.idd/MANIFEST.tsv`.
6. Run full Rusty IDD gates and affected CLI smoke tests.
