# upgrade-architecture-graph-workflow

## Why

Rusty IDD needs more than a compact code index. It needs a detailed architecture
graph that can map integrations, OpenSpec changes, ADRs, tasks, and validation
evidence to the real system structure.

The full-feature `codegraph-rust` and `repomix-rs` integrations are valuable
because they provide the two missing automation inputs: structural graph data
and bounded context packages. This change makes that role explicit in the
workflow by adding an architecture graph artifact generated from both surfaces.

## What Changes

- Add a Rusty IDD architecture graph artifact generated by the knowledge layer.
- Use CodeGraph-backed indexing for structural files, nodes, edges, languages,
  and hotspots.
- Use repomix-backed packing for context budget and package metrics.
- Map repo components, integration surfaces, and Rusty IDD lifecycle stages into
  a deterministic architecture report.
- Expose the artifact through the `rusty-idd knowledge` CLI and refresh flow.

## Capabilities

### New Capabilities

- `architecture-graph-workflow`: generate a detailed system architecture graph
  that ties code structure, integration surfaces, and OpenSpec automation stages
  together.

### Modified Capabilities

- `knowledge`: refresh now produces architecture artifacts in addition to the
  index and report.
